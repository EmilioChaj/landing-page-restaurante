# Plan: Ubicación & Contacto

## Enfoque
Proporcionar toda la información de contacto y ubicación del restaurante de forma clara y accesible.

## Implementación
1. **Location Component:**
   - Título de sección
   - Layout de dos columnas (info + mapa)

2. **Información de Contacto:**
   - Dirección completa
   - Teléfono (click para llamar)
   - Email (click para mailto)
   - Horarios de apertura
   - Iconos de redes sociales

3. **Mapa:**
   - Mapa embebido (Google Maps iframe o Leaflet)
   - Marcador de ubicación
   - Responsive (fullscreen en móvil)

4. **Horarios:**
   - Lunes a Viernes
   - Sábados
   - Domingos y festivos
