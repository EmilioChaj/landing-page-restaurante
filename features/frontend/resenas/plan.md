# Plan: Reseñas

## Enfoque
Mostrar testimonios de clientes para generar confianza ycredibilidad.

## Implementación
1. **Reviews Component:**
   - Título de sección
   - Carrusel o grid de reseñas
   - Navegación entre reseñas

2. **ReviewItem Component:**
   - Foto del cliente (avatar)
   - Nombre del cliente
   - Estrellas de calificación
   - Texto de la reseña
   - Fecha (opcional)

3. **Estrellas:**
   - Componente reutilizable de estrellas
   - Llenas, medias, vacías

4. **Datos:**
   - Array de reseñas en JSON
   - Mínimo 6 reseñas
