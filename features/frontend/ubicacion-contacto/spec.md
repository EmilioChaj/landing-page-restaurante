# Spec: Ubicación & Contacto

## Qué Hace
- Muestra la ubicación del restaurante en un mapa
- Proporciona toda la información de contacto
- Facilita la comunicación (teléfono, email)

## Requisitos
### Información
- [ ] Dirección completa
- [ ] Teléfono con enlace tel:
- [ ] Email con enlace mailto:
- [ ] Horarios de apertura (L-V, Sáb, Dom)
- [ ] Iconos de redes sociales (Instagram, Facebook)

### Mapa
- [ ] Mapa embebido (Google Maps u OSM)
- [ ] Marcador en la ubicación
- [ ] Alt: "Ubicación del restaurante"
- [ ] Responsive (100% width)

### Layout
- [ ] Dos columnas en desktop (info + mapa)
- [ ] Una columna en móvil (info arriba, mapa abajo)
- [ ] Diseño consistente con el resto

### Accesibilidad
- [ ] Enlaces de teléfono/email funcionales
- [ ] Texto alternativo en mapa
- [ ] Contraste suficiente
