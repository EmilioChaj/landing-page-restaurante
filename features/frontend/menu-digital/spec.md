# Spec: Menú Digital

## Qué Hace
- Muestra el menú completo del restaurante organizado por categorías
- Permite filtrar por tipo de plato
- Destaca platos especiales

## Requisitos
### Sección Menú
- [ ] Título "Nuestro Menú" con línea decorativa dorada
- [ ] Botones de filtro por categoría
- [ ] Grid responsive (1 col móvil, 2 col tablet, 3-4 col desktop)

### Tarjeta de Plato
- [ ] Imagen del plato (aspect ratio 4:3)
- [ ] Nombre del plato (fuente serif)
- [ ] Descripción (máx 2 líneas)
- [ ] Precio formateado (ej: €8.50)
- [ ] Badge "Destacado" para platos especiales
- [ ] Hover effect sutil

### Datos
- [ ] Mínimo 12 platos (3 por categoría)
- [ ] Datos en archivo JSON separado
- [ ] Imágenes placeholder o reales

### Accesibilidad
- [ ] Imágenes con alt text descriptivo
- [ ] Filtros navegables por teclado
