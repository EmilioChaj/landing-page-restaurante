# Spec: Galería de Fotos

## Qué Hace
- Muestra una colección de fotos del restaurante
- Permite ver fotos en tamaño completo
- Organiza fotos por categoría

## Requisitos
### Galería
- [ ] Título "Galería" con decoración
- [ ] Grid responsive (2 cols móvil, 3 tablet, 4 desktop)
- [ ] Minimum 8 fotos
- [ ] Efecto hover en cada foto

### Lightbox
- [ ] Click en foto abre lightbox
- [ ] Imagen a pantalla completa
- [ ] Navegación izquierda/derecha
- [ ] Botón cerrar (X)
- [ ] Tecla Escape cierra
- [ ] Overlay oscuro semi-transparente

### Filtros (Opcional)
- [ ] Botones: Todas, Restaurante, Comida, Eventos
- [ ] Animación al filtrar

### Datos
- [ ] Array de objetos { id, src, titulo, categoria }
- [ ] Imágenes placeholder de Unsplash o similares
