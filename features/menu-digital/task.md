# Task: Menú Digital

## Plan de Implementación

### Sub-tareas
1. **Datos del Menú** (1h)
   - Crear src/data/menu.json con 12+ platos
   - Definir estructura de datos

2. **Menu Component** (3h)
   - Crear estructura con filtros de categoría
   - Implementar lógica de filtrado
   - Grid responsive de platos

3. **MenuItem Component** (2h)
   - Card con imagen, nombre, descripción, precio
   - Badge para platos destacados
   - Hover effects

4. **Estilos** (2h)
   - Estilos CSS Modules para ambos componentes
   - Responsive design
   - Animaciones de entrada

5. **Integración** (1h)
   - Integrar en App.jsx
   - Probar con diferentes cantidades de datos

### Total Estimado: 9 horas
