# Spec: Navigation & Hero

## Qué Hace
- Proporciona navegación intuitiva a todas las secciones
- Establece el tono visual elegante del restaurante
- Invita al usuario a reservar con un CTA prominente

## Requisitos
### Header
- [ ] Logo visible en todas las resoluciones
- [ ] Enlaces: Inicio, Menú, Reservar, Galería, Contacto, Reseñas
- [ ] Botón "Reservar" destacado en dorado
- [ ] Efecto de fondo al hacer scroll
- [ ] Menú hamburguesa en pantallas < 768px

### Hero
- [ ] Imagen de fondo cubre toda la pantalla
- [ ] Texto centrado y legible
- [ ] Título: "Corte Italiana" (fuente serif)
- [ ] Subtítulo descriptivo
- [ ] Botón CTA con hover effect
- [ ] Scroll indicator animado

### Accesibilidad
- [ ] Contraste suficiente (WCAG AA)
- [ ] Navegación por teclado
- [ ] ARIA labels en elementos interactivos
