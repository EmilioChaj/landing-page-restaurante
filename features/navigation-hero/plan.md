# Plan: Navigation & Hero

## Enfoque
Implementar un header fijo con navegación suave y una sección hero impactante que establezca el tono elegante del restaurante.

## Implementación
1. **Header Component:**
   - Logo a la izquierda
   - Enlaces de navegación al centro
   - Botón "Reservar" a la derecha (CTA)
   - Fondo transparente que se vuelve sólido al hacer scroll
   - Responsive: Menú hamburguesa en móvil

2. **Hero Component:**
   - Imagen de fondo de alta calidad (restaurante italiano elegante)
   - Overlay oscuro sutile para mejorar legibilidad
   - Título principal: "La Dolce Vita"
   - Subtítulo: "Auténtica cocina italiana en el corazón de la ciudad"
   - Botón CTA: "Reserva Tu Mesa"
   - Scroll indicator animado

3. **Técnicas:**
   - CSS Modules para estilos
   - Intersection Observer para efectos de scroll
   - Transiciones CSS para animaciones
